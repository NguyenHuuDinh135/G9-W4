01 · Decisions

Key Technical Decisions.

Bedrock Agents vs Custom Pipeline
Chose managed orchestration. Agent handles KB retrieval + tool routing automatically. Trade-off: less control, faster to production.
VPC Interface Endpoint vs NAT Gateway
VPC Endpoint for API Gateway (execute-api). Keeps traffic on AWS backbone, saves ~$32/month NAT cost, reduces latency.
Lambda Chat Outside VPC
No vpc_config — calls Bedrock directly via AWS internal network. Avoids cold start ENI delays (5-10s).
What Didn't Work
DeepSeek V3.2 via Terraform foundation_model param failed. Fix: lifecycle { ignore_changes } + manual console config.

04 · Reflection

Lessons Learned.

Hardest Level: L3
Tool descriptions must be extremely precise.

"Gets data" → useless.
"Returns CURRENT live metrics; for HISTORICAL data use query_database" → works.

Iterated multiple times before agent routed correctly.
What we'd do differently
  • Add query rewriting for L4 (pronouns → explicit references)
  • Automated testing with question JSON files
  • Fallback error messages when Monitoring API unreachable
